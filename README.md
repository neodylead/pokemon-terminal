# Pokémon Terminal

A small terminal-based Pokémon game written in C++.

This project started as a way to practice and apply C++ concepts while building something fun. It is inspired by the classic Pokémon games and currently focuses on the core systems needed for a small playable prototype.

## Features

- Pokémon and Move classes
- Species data loaded from a CSV database
- Pokémon move management
- Terminal-based menus
- Battle system in development
- First-generation Pokémon data

## Built With

- C++
- Standard Library
- CSV data

## Project Goal

The goal is to build a small playable Pokémon experience while exploring C++ object-oriented programming, classes, references, inheritance, data handling, and game logic.

This is a learning project, so the code and features will evolve as the project grows.

## Status

**In development**

The basic structure is already in place, and the next major step is completing the battle system.
